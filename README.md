# سبد خرید مدرن - مهربان

## نحوه اجرا:

### روش ۱ (ساده‌ترین):
فایل `index.html` را با مرورگر باز کنید.

### روش ۲ (با سرور محلی):
1. مطمئن شوید Python نصب است
2. فایل `serve.bat` را دوبار کلیک کنید
3. آدرس `http://localhost:8080` را در مرورگر باز کنید

## ویژگی‌ها:
- ✅ نمایش محصولات با فیلتر دسته‌بندی
- ✅ افزودن حذف و تغییر تعداد محصول در سبد خرید
- ✅ خلاصه سفارش با محاسبه خودکار
- ✅ فرم ثبت سفارش با اعتبارسنجی
- ✅ صفحه تأیید سفارش با شماره سفارش
- ✅ ذخیره سبد خرید در localStorage (پس از رفراش ناپدید نمی‌شود)
- ✅ طراحی مدرن و واکنش‌گرا (responsive)
- ✅ اعداد فارسی برای قیمت‌ها

## فایل‌ها:
- `index.html` - صفحه اصلی
- `css/style.css` - استایل‌ها و انیمیشن‌ها
- `js/app.js` - منطق سبد خرید
- `serve.bat` - اجرای سرور محلی
